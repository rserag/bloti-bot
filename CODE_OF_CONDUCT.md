# Code of conduct

Bloti Bot contributors and maintainers are expected to keep project spaces respectful, inclusive,
and focused on constructive collaboration.

Harassment, discrimination, threats, unwanted sexual attention, deliberate disclosure of private
information, and sustained disruptive behavior are not acceptable. These expectations apply to
issues, pull requests, discussions, and other project-related communication.

Maintainers may edit or remove content and may temporarily or permanently restrict participation
when behavior is inappropriate. Decisions should be proportionate, documented privately when
possible, and made without retaliation.

Report abusive GitHub content through [GitHub's reporting tools](https://support.github.com/contact/report-abuse).
For project-specific concerns, contact the maintainer privately using the contact information on
the [maintainer's GitHub profile](https://github.com/rserag). Do not include sensitive personal
information in a public issue.
