# Support

For usage questions and confirmed non-sensitive bugs, open a GitHub issue using the appropriate
template. Include the Bloti Bot version, deployment method, expected behavior, and sanitized error
messages.

This is a community-maintained project with no guaranteed response time. Please do not post bot
tokens, API credentials, Telegram session files, private chat content, or personal information.

Potential vulnerabilities must be reported privately as described in [SECURITY.md](SECURITY.md).
